离线预览，不是完整应用部署

此页面可直接双击打开，不依赖网络、Node.js 或 npm。

积木定义、碰撞校验、事务回滚、合并、字段绑定及明细规则直接来自原工程的 src/domain，仅视图和状态容器替换为原生 HTML / JavaScript。

可验证：拖放、字段配置、样式、行高列宽、合并、撤销重做、整体移动与 JSON 导出。

不包含：Univer 原生画布、Pinia/Vue 运行时、ExcelJS 文件导出以及 C# 宿主通信。这些功能保留在完整源码中，本次尚未完成其浏览器构建验证。

完整应用：安装 Node.js 22.6+，解压代码包，运行 start-windows.cmd（首次需联网安装 npm 依赖），或使用 npm start。
