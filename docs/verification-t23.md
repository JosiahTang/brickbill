# T23 验证记录

已验证：生产配置缺项目、令牌或 PDF 依赖时启动检查给出错误；`REPORTING_DEMO_PROJECTS=disabled` 可关闭内置模拟项目；前端开发服务器将同域 `/api` 转发到生成服务；后台健康检查与项目授权按预期工作。

部署集成测试以真实 Node 服务进程启动模拟项目，借助现有 Excel 模板导入和生成链路发布模板、按合成打印号生成 XLSX，下载后核对快照哈希。停止并重启服务进程后，使用同一数据目录重新读取模板版本、生成快照和文件，再次重印所得哈希相同。

`npm run test:deployment` 覆盖上述启动和重启路径；`npm run verify` 继续执行既有领域、Schema、Excel、PDF、API、宿主测试及类型检查、生产构建。

开发主机没有可用的 Docker 命令或 Engine，因此这里没有声称已构建或运行 Compose 镜像。容器镜像下载、PDF 字体挂载、命名卷备份恢复、部署网络入口和目标办公软件实印，需在目标环境按 [部署说明](../deploy/README.md) 完成现场验收。
