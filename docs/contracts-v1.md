# 报表引擎数据契约 v2

本文描述 T01 实际建立的跨项目数据结构。契约以 JSON Schema 为运行时校验依据，以 `src/core/contracts/types.ts` 为 TypeScript 类型入口。契约版本字段使用整数 `2`；项目、适配器、模板、目录、视图和函数各自维护独立版本。

## 契约入口

版本化 Schema 位于 `schemas/v2/reporting-contract.schema.json`。`validateContract(kind, value)` 提供运行时校验，可校验项目定义、字段目录、数据集、数据视图、已注册函数描述、模板包、分页计划和生成快照。校验错误具有 `code`、`stage` 和可选 `context`，前端及服务可按同一结构显示。

核心类型位于 `src/core/contracts/types.ts`。数据接入方传输 `DatasetBundle`，以项目及文档类型限制数据范围；字段目录标识可绑定字段及其粒度；数据视图只描述已支持的操作；模板通过视图、函数和字段目录的版本号固定依赖。

## 数据粒度和关联

项目定义为每个集合声明业务粒度、必需状态、复合主键和字段类型。关系声明父子集合及两端关联键，描述 `one-to-one` 或 `one-to-many`。一个打印号可以作为采集入口，同时结合接箍标识等业务参数选定文档类别。数据包保留多个集合和记录，不要求把一对多集合摊平成同一表。

`DatasetBundle` 的每条记录都具有 `recordId`、稳定字段标识对应的 `values`，及可选来源记录标识。适配器依据配置的复合键生成可重复 ID；遇到缺键、重复键或无效类型时，采集失败并指出集合及源字段。来源时间和版本记入数据包，供后续生成快照使用。

## 字段目录与视图

字段具有稳定 `fieldId`、类型、可空状态、粒度、单位和来源。来源可为项目数据集、已发布视图、常量、受控参数或页面系统值。显示名称、Excel 数字格式属于呈现信息，改标签不改变字段标识。无来源字段不能作为业务数据发布。

视图从一个数据集开始，按配置顺序执行筛选、排序、投影、分组聚合、透视、受控一对一查找和注册函数；可以用声明关系把子视图挂载到父记录。透视列和值都显式配置。相同分组键出现多个值时必须使用拒绝、求和、平均、最小或最大策略。视图引擎不提供任意 SQL、脚本、隐式丢重或“自动取第一条”策略。

每个结果记录携带来源记录标识。跨数据集汇总需使用与指标粒度相符的视图；成分和力学结果作为不同集合挂载，避免一对多互相乘增。

## 模板包、分页计划与快照

`TemplatePackage` 是 T07 将实现的包级保存格式。T01 定义其稳定契约和 v0.2 单工作表迁移方法。迁移函数保留单元格坐标、格式、区域和原路径绑定，并将原 XLSX 字节集中保存在包中一次。迁移后的绑定标记为 `legacy-path`；以后通过明确字段映射升格为稳定字段标识。迁移包初始为草稿，不能自动发布或虚构数据视图引用。

`PagePlan` 表达模板版本、逐页类型、逐区域记录分配、业务组键及补白数。它只作为生成计划，不能回写 MES 表中的页码字段。`GenerationSnapshot` 固定采集数据、目录、视图、函数和模板版本，可存储最终页计划及输出文件校验信息。

## 项目适配器

适配器把项目特有的单号、源列名和类型映射到标准数据集合。T03 的映射配置以项目维护，不放到客户模板中。HTTP 模式调用项目提供的受控只读数据接口；本地和桌面宿主可通过相同 `ProjectAdapter` 接口接入。服务端根据已登记的项目配置选择适配器，调用方不能用模板参数传入任意 URL 或 SQL。

契约定义仅提供静态格式约束；数据库字段实际语义、关系键和正式检验规则仍须依据项目源表和业务确认材料映射。
