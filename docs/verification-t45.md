## 兼容与行为约定

- 包 contractVersion 2、文档 schemaVersion 1、图片 imageLayoutVersion 1 不变；比较套件 v1/v2、比较报告及部署证据 v2/v3/v4 均未修改。
- 字段变更及文档替换的操作信息仅以 WeakMap 关联现有历史快照，通过 Vue toRaw 读取；不写入模板、已发布版本、IndexedDB 草稿或生成快照。关闭/重新打开模板仍按原行为重建运行时历史。
- 沿用原有 past/future、工作表历史及 100 项限制。普通文字、绑定和图片撤销不恢复过时字典；字段撤销对比本次涉及字段，拒绝覆盖较新定义。删除候选字段若仍被其他表绑定，验证失败且历史游标不动；不自动删绑定。
- 字典修改及撤销同步各表绑定的路径、稳定字段 ID、类型和数字格式，复用 updateWorksheet/包校验。旧文档及原工作簿继续由原包适配保存，不在工作表中重复嵌入整本 Excel。
- 原始文档 ID 可能重复，文档替换必须归属于具体历史项。普通撤销不会仅凭相同 ID 被误判为模板替换。真正替换的撤销/重做仍恢复相应包并推进加载会话。
- 文件导入、本地草稿恢复先准备后接纳；失败不替换原稿、不推进加载会话。导入期间的新编辑或新上下文使旧结果失效，可重新发起。服务端草稿/版本打开同样保护等待期间的新编辑。
- 试算序号随请求归属变化推进，包括改动后再改回；请求和结果使用发起时的指纹。已有结果在配置变化后仍由 ViewTrialResults 标记过期，新返回的旧结果不会获得当前指纹。旧失败不会覆盖当前错误或弹出旧错误提示。
- 目录请求固定项目、目录版本、选择范围及模板加载会话；同一模板的后续手工编辑保留，返回时按最新字典去重。无效批次、网络失败不写关联或部分字段；目录版本变化明确要求刷新。
- ImageResources 的内部资源事件改为同步提交回调，错误可返回原上传表单；不改变持久化契约。两个有效上传均按最新包资源合并；较旧上传完成不改变较新的上传或手工选择。换工作表仍属于同一包，重新加载相同 packageId 则由 loadEpoch 区分。
- 图片提交前父级再次检查实际 loadEpoch，避免子组件属性更新前的时间窗口。校验失败不会将未保存 ID 设为已选；资源复用不重复写入。5 MiB 单图及 20 MiB 包限制沿用原实现。
