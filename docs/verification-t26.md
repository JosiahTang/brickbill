# T26 完成与验收记录

T26 已完成通用数据映射与业务基准对照能力，不新增数据库驱动或项目特定比较逻辑，并复用现有项目注册、HTTP 只读适配器、字段映射和视图引擎。

实现包括：

- 可审阅的版本化 JSON 对照套件，覆盖项目、业务键、数据集/视图、复合记录键、字段值、记录数、顺序和数字容差。
- 通用比较器，可报告目标缺失、重复复合键、记录数量差异、缺失/多余记录、字段值差异和顺序差异；复合键编码沿用现有碰撞安全实现。
- `project:compare` CLI 的离线快照和在线只读 HTTP 模式，输出含数据版本、数量及逐项差异的 JSON；失败用例返回非零退出码。
- 达力普与通用 MES 两套合成基准。对照测试还发现并修复了 MES 元素符号列名转换问题。
- 使用说明见 [项目对照文档](project-comparison.md)，完整任务验收条件见 [编程任务清单](programming-tasks-v1.md) 的 T26。
