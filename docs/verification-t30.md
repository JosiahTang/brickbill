# T30.1—T30.6 实现与验收记录

本轮实现沿用既有 DataViewEngine、固定分页规划器、模板/视图版本仓库、匹配条件仓库及原子 JSON/生成快照存储，没有增加依赖或另一套执行链路。

## 已完成的代码范围

- **T30.1 / T30.6.1**：模板发布和只读预检共用视图、附页条件、子集合、确定性函数依赖解析。新增预检接口只检查当前修订并返回将锁定的引用，不写版本、不访问 MES。固定试算使用 `templateRef` 从服务端加载不可变模板；单视图试算不带页面包。
- **T30.2 / T30.6.2**：服务端仍在仓库写锁中核对预期修订。界面分别记录编辑基准与远端观察修订，刷新保留本地内容；版本不同时提示用户显式重载，过期写入由服务端拒绝。
- **T30.3 / T30.6.5**：复用已有匹配条件和模板版本资源，覆盖表单保存、查询、删除、复制、停用、恢复和只读命中诊断。
- **T30.4 / T30.6.4**：现有原子 JSON 和快照目录重命名对 Windows `EPERM`、`EBUSY`、`EACCES` 有有限退避；幂等键保持同请求重试可复用。批量视图发布按父子依赖发布；相同内容复用已发布版本，发布完成后更新并保存模板视图引用。
- **T30.6.3**：发布重试会先比较远端草稿内容；相同草稿不再递增草稿修订，同内容发布复用旧版本，变化内容才新增版本。同步保存本地模板中的视图引用。
- **T30.6.6**：扩展两个项目的浏览器用例，包含批量重试版本稳定、模板预检、固定版本分页试算、生成、签发和历史文件重用。
- **T30.3**：现有模板匹配条件可从登记业务参数表单配置，规则可查询、删除、复制到新版本；新增只读候选命中诊断。界面可停用及恢复模板，并显示未命中条件、命中模板、优先级或歧义。
- **T30.4**：原子 JSON 与生成快照目录提交对 Windows `EPERM`、`EBUSY`、`EACCES` 短暂失败进行最多 4 次退避重试。生成按钮显示并遵从忙碌状态；模板、版本、单据类型或业务参数变动会产生新的请求幂等键，失败时保留当前键供相同请求重试。
