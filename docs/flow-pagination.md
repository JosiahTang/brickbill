# T21 流式分页配置

流式分页沿用 T11—T20 的视图、页面计划、逐页投影、Excel 导出和项目生成服务。页面定义必须显式设置 `paginationMode: "flow"`；旧模板未设置时继续使用固定版式。页面类型为 `main`，续页若存在，须使用相同模式和同一明细区域 ID。

一个流式页面目前使用一个明细区域（`kind: "detail"`）和一个业务视图。可选的 `groupHeader`、`groupFooter` 区域必须与明细区使用相同的工作表、视图、分页组和 `groupBy`。这两个区域是设计在 Excel 样板中的行样式；生成时按业务组复制到实际位置。组尾字段可使用 `aggregate.scope: "group"` 求和、计数、平均值、最小或最大值。组头与至少一条明细同页，长组按 `oversizedGroupPolicy: "split-records"` 续页时重显组头。未授权拆组时返回 `GROUP_TOO_LARGE`。

表头放在流式区域上方，设为 `header` 并配置 `repeatHeaderRows`。末页合计或声明放在 `footer` 区域，设置 `repeatOn: "last"`；放入合计字段时可用 `aggregate.scope: "document"`。页面计划为最后一页预留该区域，其余页可用到打印范围末端。普通每页页尾使用 `repeatOn: "all"`，始终预留。若有附页，`last` 表示整个文档最后一页。

流式明细从明细/组头/组尾样板的最早行开始，向下占用到固定页尾或打印范围末端；`capacityRows` 可设置更小的上限。这个范围是流式画布，内部静态内容会被清除并由分页条目替换。文本按列宽、字号、换行设置估算所需行高；无法在单页容纳一个带组头的记录时明确报错。带 `wrap: false` 且宽度不足的文字也明确报错。导出的每一页仍是一张独立工作表，沿用同一页计划和 XLSX 回读校验。

当前流式模式不支持同一页面并排的多个明细区域，也不支持明细字段跨变高行纵向合并。此类模板继续使用固定版式，或把并排数据在视图中整理成同一行。文本测量是字体宽度估算；正式使用仍需用目标办公软件和真实样本检查分页与实印。执行 `npm run verify` 可回归流式与固定版式。
