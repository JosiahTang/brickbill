# 模板与生成契约 · v0.2

## 保存与恢复

`TemplateDocument` 为编辑状态来源。`schemaVersion: 1` 保持兼容，在原模型上增加可选 `fields`、`repeatRegions`、`excelSource`。无 `fields` 的旧文件使用内置字典。

保存 XLSX 时写入非常隐藏的 `_brickbill_template` 工作表：A1 为 `BRICKBILL_TEMPLATE_V1`，A2 起每格存储最多 30000 字符的 JSON 片段，依次拼接为文档。嵌入文档剔除原 Excel 的 Base64 字节，避免重复保存指数膨胀。导入已保存文件时恢复此文档，将新文件作为排版来源。外部改动工作表不会自动合并进隐藏文档。

浏览器保存请求下载此单文件；JSON 是可选独立导出。宿主 `SAVE_TEMPLATE` 的 XLSX、document、metadata 仍使用同一修订号快照。无新增后端持久化接口；WebView2 / CefSharp 需由宿主按既有协议接入。

## 字段字典

每个字段包含 `path`、`label`、`format: text|number|date`，可选 `collection`、`group`、`required`、`example`、`numberFormat`。

只支持安全的点分属性路径；禁止 `__proto__`、`constructor`、`prototype`，读取仅使用对象自身属性。没有表达式、eval、SQL 或函数调用。

`collection` 为数组绝对路径，字段必须是其下级属性。例：`heats.tests.C` 的集合为 `heats.tests`。JSON 推断遍历所有记录，保留已有定义；不从空数组猜测结构。

## 明细区域

`repeatRegions` 项目为 `{id,name,source,rect,empty,parentId?}`。`rect: {r,c,rows,cols}` 为 0 基坐标，定义一条记录的完整样板。`rows` 可大于 1；`empty` 为 `keep` 或 `remove`。

每个顶层区域从根数据读取数组，每个子区域相对父记录读取子数组。子 `source` 必须以父 `source + '.'` 开头，子区域必须完全位于父区域内。支持多个独立区域重复使用同一集合。独立区域的行范围不能相交；嵌套最多 8 层。

扩展按整行进行。区域范围外的值只保留一份，内部样板内容按记录复制；后续所有列整体下移。父记录合并单元格如跨越子明细行且列范围不相交，会随子记录伸展。其他跨样板边界的合并会被阻止。

生成先递归规划输出行、源行映射和父子上下文，再投影值、行高、格式及合并，避免多个检验区互相覆盖。没有修改原模板。空数组根据策略移除或保留空样板；保留空样板不触发明细必填错误。

## 类型与错误

根数据必须为对象，集合须为对象数组。文本可接收字符串、数字、布尔；数字必须为有限 JSON number，日期须为有效 ISO 日期。数值零不是空值。缺失必填值和错误类型阻止生成；非必填缺失及未提供集合返回可见警告。占位符是字符串，生成时写入实际数字或 Excel 日期。

公式在模板保存时保留；若扩行改变行映射，存在 Excel 公式时生成明确失败，调用方应提前计算并作为字段提供。未实现跨表公式引用重定位、Excel 公式重算、按页小计、横向扩列和并排独立数组。

## Excel 与打印

保留原工作簿作为导出来源，用文档投影编辑工作表，保留其他表、图片和常规页面设置。生成结果更新打印范围，并按照源行映射移动图片锚点；区域内图片不逐记录复制。图表、宏、透视表等特殊对象不保证保留。导出依赖 ExcelJS，不宣称与所有 Excel 特性完全兼容。

生成结果不嵌入编辑元数据；模板文件与生成结果是两种不同用途的文件。

## 限制与验收

输入文件 20 MiB；字段最多 1000 个；区域最多 100 个；文档 / 输出最多 10000 行、200 列、500000 单元格；业务 JSON 界面限制 5 MiB。预览只显示前 200 行，不截断 Excel 结果。

`tests/workflow.test.mjs` 覆盖字段维护、异构数组推断、0/1/多条记录、多行样板、嵌套不等长明细、区域冲突、必填和类型、合并伸展、页脚迁移、宽模板和窄列、Excel 图像/日期/公式/样式回读、嵌入配置恢复及重复保存体积。
