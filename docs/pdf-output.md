# T22 固定版式 PDF 输出

PDF 适配器直接读取服务端保存的不可变逐页投影。分页、业务数据收集、字段解析、图片资源和模板版本均沿用 XLSX 的生成链路；不按客户或项目开发第二套展示后台。当前只开放 `paginationMode: fixed` 的页面。流式页仍可预览和导出 XLSX，但不能下载 PDF。

## 部署选择与开关

部署渲染器选择 **Python 3.12 + ReportLab 4.4.9 + Pillow 12.3.0**。它按投影给出的纸张、边距、行列尺寸、合并、文字、边框和图片坐标直接绘制 PDF，无需安装办公软件。应用运行账户必须能读取 Python、字体文件，并能在系统临时目录写入临时文件。服务每次渲染会校验 ReportLab 版本和输出物理页数，生成结果记录渲染器版本、使用的字体路径、页数和每页缩放比例。请在部署镜像/环境中固定这三个依赖版本；不要在请求过程中安装依赖。

以下环境变量由服务进程设置：

| 变量 | 含义 |
|---|---|
| `REPORTING_PDF_PYTHON` | 已安装上述依赖的 Python 可执行文件绝对路径 |
| `REPORTING_PDF_FALLBACK_FONT` | 可嵌入、覆盖业务文字的 TTF 字体绝对路径 |
| `REPORTING_PDF_FONT_MAP_JSON` | 可选，模板字体名到 TTF 文件绝对路径的 JSON 对象；粗体可用 `字体名#bold` 指定 |
| `REPORTING_PDF_REPORTLAB_VERSION` | 预期 ReportLab 版本，默认 `4.4.9` |
| `REPORTING_PDF_MIN_SCALE` | 页面允许的最小缩放比例，默认 `0.85`；低于此值返回布局错误 |
| `REPORTING_PDF_TIMEOUT_MS` | 单次渲染超时，默认 90000 毫秒 |
| `REPORTING_PDF_ENABLED_PROJECTS` | **单独验收后**开放的项目 ID，逗号分隔；默认空，即不开放任何项目 |

字体映射只接受服务器配置，模板不能提供可执行路径。缺少字形、图片资源损坏、文字超出单元格、合并越界、页面缩放过小、公式尚未计算等情况会返回明确错误，不会静默输出可能缺字或裁切的 PDF。字体文件不随仓库分发；项目上线前由部署方确认实际字体的嵌入和分发授权、ReportLab/Pillow 的许可义务，并把获准使用的字体与版本固定在部署清单中。

服务启动后，生成响应和状态响应仅在该项目已开放且对应模板为固定版式时返回 `pdfUrl`。调用 `GET /api/projects/{projectId}/generations/{generationId}/file.pdf` 下载。首次请求从生成快照渲染 PDF，之后读取经 SHA-256 校验的 PDF 侧车文件；重印不重新采集 MES 表，也不重新运行视图规则。已缓存的 PDF 即使渲染环境临时下线仍可重印。PDF 下载与 XLSX 下载使用同一项目身份校验。

## 验收和开放

每个项目/客户模板需单独拿批准的 XLSX、示例业务单号及基准 PDF 或实印件验收。至少核对：物理页数与页码、每页明细边界、长分组和末页汇总、合并单元格、表头/页脚、全部字体及中英文数字、图片与签章位置、纸张方向和尺寸、最窄单元格有无裁切。复杂模板还要在目标打印机/纸型下实印。使用实际部署字体和运行环境生成；业务方确认视觉基准后，才将项目 ID 写入 `REPORTING_PDF_ENABLED_PROJECTS`。

本仓库的合成两页样例和测试只证明通用链路可用；它不代表图片中客户质保书的签章、排版或业务数值已获批准。T22 本机验证记录见 [verification-t22.md](verification-t22.md)。
