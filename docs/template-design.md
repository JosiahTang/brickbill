# 质保书模板制作

在设计器导入客户原始 `.xlsx`，确认工作表、合并单元格、尺寸和打印范围，再从项目字段目录选择稳定字段 ID 拖到目标格。固定值放在证书头；多行物料、化学、力学、硬度及无损/工艺检验分别定义明细区域，绑定对应视图。对同一炉批联动分页的区域配置相同 `paginationGroupId` 和 `groupBy`；本例用 `report.heatNo`、`report.lotNo`。每个区域的 `capacityRows` 由该模板实际版式确定，不从 BFR 旧代码抄全局页容量。

特殊附页使用 `pageType=appendix`，在区域上设置 `appendixIfViewHasRecords`。页码和总页数用页面字段，不写入业务表。合同检验要求、正式结果、单位转换和特殊文本规则应在采集快照或版本化视图/函数中明确，不把复杂 SQL 拼在单元格里。签章资源仅在授权的真实素材取得后配置位置和重复规则；示例不伪造印章。

同一项目制作第二套模板时，继续引用相同的字段目录和视图版本，另配工作簿、区域顺序和页容量。操作顺序为：导入 → 检查保真提示 → 字段绑定 → 设置分页和附页 → 用已知业务单号预览 → 下载 XLSX 回读 → 保存草稿 → 发布 → 以明确版本或匹配规则生成。校对时逐页核对值、记录数、顺序、汇总、签章、字体、缩放和实印；复杂公式如需随分页移动，应先转为业务字段或确认当前公式支持范围。
