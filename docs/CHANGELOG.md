# v0.2.0 · Excel 模板与可维护字段字典

- 移除新版界面中的积木入口；新增字段管理、JSON 推断、搜索分组和必填 / 类型 / 数字格式设置。
- 支持 XLSX 导入、工作表选择、复杂合并、宽模板、窄列、原值与样式保留、字段拖拽替换及缩放定位。
- 独立明细区域、多行样板、多个检验区、嵌套数组、不同子记录数量、父合并伸展及后续区域迁移。
- 生成预览和实际业务 Excel；模板内嵌字段 / 区域配置，可导入恢复；IndexedDB 自动草稿。
- 质保书示例和业务数据；新增 18 项流程测试。完整校验 70 项通过，Vue / TypeScript / Vite 构建成功。
- 旧积木领域模型和宿主消息接口保持兼容；没有新增后端服务或在线部署。

## T14—T17 · 分页生成、预览与统一服务首版

- 新增分页 XLSX 输出：按逻辑页生成可见工作表，回读核对值、样式尺寸、合并、图片锚点和打印区域；无法安全重定位的公式会明确拒绝。
- 新增按页读取的完整预览，支持翻页、缩放、同页多工作表切换、图片和错误定位；预览与下载沿用一次生成快照。
- 新增项目隔离的模板 / 视图版本、资源和快照本地存储，具备修订冲突检测、不可变发布、幂等生成和原文件重印。
- 新增统一 Node.js HTTP 参考服务、自动模板匹配，以及宿主 v1 兼容和 v2 能力协商。
- `npm run verify` 全量通过；额外集成用例确认 205 条明细可跨页完整读取。真实 MES、目标办公软件实印和生产身份接入仍待项目验收。

## T07—T13 · 模板包、页面定义与固定分页首版

- 将 XLSX 多个可见工作表作为一个模板包导入、保存和恢复，原始工作簿只在包级保存一次；支持工作表重命名、排序和独立撤销历史。
- 字段字典增加稳定 ID、数据源/视图/常量/参数/页面来源、布尔类型、跨表共享编辑和引用保护；JSON 自动推断遍历多行及嵌套集合。
- 设计器增加受控数据视图草稿和页面配置，支持纸张、打印区域、页边距、重复表头、主表/续页/附页、多明细区域联动、排序、合并/重复值规则和条件附页。
- 新增布局测量与诊断、确定性固定分页、超大组显式续页、页码/序号/汇总字段解析及逐页文档投影；不更改输入模板或业务记录。
- 新增三工作表模板包往返、共享字典、分页收敛、超大组、页面投影、图像引用和边界校验用例。
- 此阶段结束时，视图试算、全部页面预览和分页 XLSX 输出列为后续 T14—T17；已在下一阶段完成首版，验证及剩余边界见 `verification-reporting-v1.md`。
