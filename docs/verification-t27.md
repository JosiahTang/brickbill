# T27 实现与验收记录

T27 将 `project:compare` 扩展为已生成质保书的输出验收流程。实现沿用现有套件校验、复合键编码、`LocalSnapshotRepository.get/readFile`、仓库 `sha256`、`loadExcel` 和分页导出器回读校验；不重新采集 MES 数据，不新增生成器或第二套验收框架。

## 已交付

- T27.1：套件支持 generationId、固定模板版本、页数/页面类型、页内区域记录键和 XLSX 版式基准；保留 T26 offline/online 套件格式。
- T27.2：新增 `--mode snapshot --data-dir`，仅读取已有快照与 XLSX，不加载项目注册、密钥或写入型运行时。
- T27.3：比较项目、业务键、模板版本、总页数、页面类型及顺序、连续页码和区域内业务记录键顺序；可精确约束页面区域集合，识别区域内与跨页重复记录。
- T27.4：通过现有 ExcelJS 回读能力比较工作表、关键单元格值/类型/数字格式、完整合并区、图片数量/锚点和打印设置。
- T27.5：JSON 报告包含 generationId、模板版本、页数与类型、产物文件名/哈希/字节数，并将差异定位到页面、区域、工作表和 A1 地址；缺快照、缺 XLSX、完整性不符或断言失败均返回非零。
- T27.6：测试复用现有两个项目、模板安装入口和临时生成仓库，期望值采用静态配置或现有样例中的业务键。

## 验证结果

- T27 定向回归：通过。覆盖达力普单页及物料顺序、达力普 16 页输出（14 个主页面、2 个硬度附页），静态夹具逐页核对 42 条物料键和 24 条硬度试样键；另覆盖通用 MES 客户版模板和不同项目隔离。
- 负向回归：通过。错误模板版本、错误页数、错误单元格值、明细顺序倒置、缺失 generation、缺失 XLSX、SHA-256 不匹配及跨页重复明细均被识别。
- T26 offline/online 对照用例在同一接入测试中继续通过。
- 完整 `npm run verify`：主测试 93 项通过；Schema 3 项、Excel 3 项、API 1 项、部署 3 项、宿主 2 项通过；PDF 1 项通过、3 项因本机未配置 PDF runtime 而跳过；TypeScript 检查和生产构建通过。
- `git diff --check` 与 Markdown JSON 示例/多页夹具解析：通过。

## 验收边界

仓库中的 Dalipu 与通用 MES 记录是合成样例，不代表真实客户业务结果已获确认。生产验收仍须由业务提供脱敏源数据、固定模板版本和独立认可的分页/单元格基准，并使用目标 Office/WPS 及字体环境检查实际打印效果。
