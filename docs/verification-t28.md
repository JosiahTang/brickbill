# T28 实现与验收记录

T28 补齐模板选择、业务参数输入、预览确认签发和历史检索闭环。实现复用已有模板版本仓库、生成快照、逐页预览、XLSX 文件和重印接口；不增加第二套数据采集、转换、分页或导出链路。

## 已交付

- **T28.1 快照断言**：`project:compare --mode snapshot` 对快照中的数据集/视图执行套件断言，并核对单据类型；数据差异与页/XLSX 差异合并到原报告。纯输出套件和 T26 offline/online 保持兼容。
- **T28.2 模板目录**：按项目列出模板草稿、最新发布版本和停用状态；界面可打开指定发布版本或草稿，修改后保存为草稿并发布新版本。已发布版本只读；停用模板可查看历史版本但不能生成。
- **T28.3 参数表单**：按项目业务键目录显示字段，校验必填、数字和日期参数。高级 JSON 入口仍可用，但只接受已登记字段。
- **T28.4 预览签发**：生成 API 只接受 preview。用户检查预览后调用该 generationId 的 issue 接口。操作者从服务端授权器读取；请求体传入的身份被忽略。签发校验原 XLSX 的字节数和 SHA-256，并以并发幂等方式写入签发人、时间和状态，不重新采集或导出。
- **T28.5 历史查询**：支持业务键关键字、模板、预览/签发状态、日期及分页；每页最多 100 条。历史列表读取轻量摘要文件，首次访问旧记录时补建摘要；预览、下载与重印读取原生成快照。
- **T28.6 流程回归**：扩展 snapshot、API 和 Playwright 覆盖数据断言、模板目录、直签拒绝、认证操作者、并发重复签发、快照文件不变、历史筛选/索引补建/下载/重印及完整多页流程。

## 验证结果

- `npm run verify`：通过。主套件 93 项；Schema 3 项；Excel 3 项；PDF 1 项通过、3 项因本机未配置 PDF runtime 跳过；API 1 项；部署 3 项；宿主 2 项；类型检查和生产构建通过。
- `npm run test:api`（最终签发契约改为“先预览、后签发”后的复核）：1 项通过，覆盖未提供操作者拒绝、请求体身份伪造无效、并发重复签发复用签发时间、原 XLSX 字节不变、历史索引补建和重启后签发元数据保留。
- `npm run test:e2e`：1 项浏览器流程通过，覆盖导入 Excel、字段拖拽、分页设置、模板发布、参数表单、逐页预览、签发、历史查看及下载哈希一致，再输入第二个业务号生成多页附页。
- `git diff --check`：最终工作树通过。

## 生产接入说明

内置本地开发授权器返回 `loopback`；令牌示例授权器返回令牌的 SHA-256 短指纹，这只是认证凭据标识，不等于员工账号。接入企业认证后，宿主授权器应提供稳定员工/服务账号 `actorId`，并按项目限制签发权限。当前参考实现使用单进程文件锁；多实例部署前应使用支持事务/唯一约束的共享存储实现并发签发。

模拟项目和页面使用仓库合成样例。真实 MES 字段映射、客户模板与打印效果仍需使用业务认可的数据和 Office/WPS 环境单独验收。
