# T22 验证记录

验证环境：Windows，Python 3.12.14，ReportLab 4.4.9，Pillow 12.3.0，字体使用本机 SimHei TTF。测试数据为合成质保书，未包含任何被遮挡的真实客户资料。

- `npm run test:pdf`：固定页面逐页投影生成两页 PDF，验证页数、文字、字体嵌入、每页印章图片和投影不变；流式页、缺字及未计算公式被拒绝。
- `npm run test:api`：验证项目开关关闭时拒绝 PDF，开放后状态给出下载地址；下载结果缓存并校验哈希；渲染环境撤销后仍可读取缓存；跨项目身份不能下载。
- `npm run verify`：覆盖已有领域、Schema、Excel、API、宿主协议、类型检查和构建，并包含 PDF 测试。
- 用 Poppler 将 [合成样例](../output/pdf/t22-validation-sample.pdf) 的两页分别渲染为图片逐页查看；确认标题/合并、明细、页脚、中文字符和红色合成印章均可见且未裁切。PDF 文件的物理页数、文本与图片同时由 pypdf 检查。

**生产验收边界**：本仓库没有用户图片所对应的原始可编辑 XLSX、真实签章资源、脱敏业务样例或批准的 PDF/实印基准，不能代替客户模板的视觉验收。项目开关默认关闭。生产开放前按 [PDF 输出说明](pdf-output.md) 对每个模板完成对照、授权和实印确认。
