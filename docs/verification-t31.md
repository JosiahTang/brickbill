# T31 实现与验收记录

T31 复用项目注册、数据适配器、模板规则仓库、固定模板版本、页面规划器和生成快照。没有增加新的采集器、规则引擎、分页器或客户专用后台。

## 完成范围

- **T31.1**：项目契约增加可选 `templateMatchFields`，映射匹配键到源数据集字段。Schema 与项目语义校验引用存在且不与业务查询参数重名；未配置的既有项目保持兼容。示例项目登记 `customer → certificate.header.cert.customer`。
- **T31.2**：生成前检查当前模板规则。规则引用采集字段时，服务端先采集一次、解析可信值并用同一 DatasetBundle 继续匹配和生成；纯业务参数规则不触发额外的匹配采集。
- **T31.3**：采集字段必须非空、最多 200 字符；同一映射数据集多行值必须一致。空集合、空值和冲突分别返回可定位错误。HTTP 生成和匹配试算都拒绝客户端传入采集字段。
- **T31.4**：项目服务界面列出业务参数及 MES 匹配字段来源，匹配试算在候选规则需要时显示采集事实，生成结果显示客户事实、命中规则和优先级。
- **T31.5**：生成快照及紧凑历史索引保存匹配事实来源、参与记录数、条件、优先级和模板版本；新增字段可选，兼容旧快照和旧历史索引。
- **T31.6**：覆盖 Dalipu 与通用 MES 两个项目的同流程客户模板选择，以及参数模板、客户模板、重复采集、伪造输入、空集合、冲突值、历史追溯和前端流程。字段空值/超长及多行同值的独立回归仍需补充，不将空集合测试等同于这些场景。

## 验证结果

- `npm run verify`：通过。主测试 102 项、Schema 3 项、Excel 3 项、API 1 项、部署 3 项、宿主 2 项通过；PDF 1 项通过，另 3 项因本机未配置 PDF runtime 跳过；TypeScript/Vue 检查和生产构建通过。
- `npm run test:e2e`：3 项通过，包含两个项目服务配置页面及客户字段条件的自动匹配生成流程。
- 双项目服务级回归确认 Dalipu 和通用 MES 均可用相同逻辑按客户数据选模板，每次生成只采集一次。

真实客户 Excel、脱敏 MES 正式样本、经业务认可的 BFR 输出和目标 Office/WPS 实印尚未提供，生产版式验收继续按 T30.5 执行。

2026-10-13 代码复核发现未使用字段、停用候选和编辑基准切换等边界，见 [工程评估与 T32 计划](engineering-assessment-t32.md)。本记录描述 T31 已实现和已测范围，不表示所有组合场景及生产验收均已完成。
