# T29 实现与验收记录

本阶段沿用已有采集适配器、DataViewDefinition、DataViewEngine、FunctionRegistry、分页规划器、模板包、资源仓库和 Excel 导出/回读检查。新增内容为配置组件、项目目录读取及原试算接口的草稿参数；没有新建规则 DSL、分页算法、导出器或项目专用数据展示后台，也没有增加依赖。

## 交付核对

- **T29.1**：`designer-metadata` 在原项目鉴权之后返回项目定义、目录、已有视图及注册函数描述。字段选择组件显示中文名称、类型和稳定 ID；字段范围按步骤变换更新。其他项目的模板草稿不能混入当前项目选择器；未关联 Excel 可以在项目服务中关联所选项目。
- **T29.2**：七种步骤全部有表单，支持添加、更新、删除和调整顺序；公共函数仅来自现有注册表，参数按类型转换。父子集合使用已有关系，自动生成完整复合关联键，并筛选保留关联键的子视图。高级 JSON 经契约检查后回填表单。
- **T29.3**：原 `views/preview` 接收未保存定义，与项目已有定义按 ID 合并，在同一引擎中执行。返回版本及 draft/published 来源、记录数、表格数据、来源记录标识。主记录默认每视图 100 条、最多 200 条；子集合按每个视图共享同样的限量预算，并返回截断标识。试算不保存视图、模板、快照或 XLSX。
- **T29.4**：分页字段及排序由选择器/表单配置；容量直接调用现有固定分页容量计算。分页试算从当前未保存表单构造临时模板，执行原包校验和分页规划器。错误定位可打开相应区域或视图步骤。区域范围独立保存，定位图片不隐式修改明细范围。
- **T29.5**：支持 5 MiB 以内 PNG/JPEG 上传、实际图片解码检查、缩略图、相同字节复用、选区锚点和重复页设置。资源暂存模板包，保存到项目服务时复用原资源仓库；模板图片总量保持 20 MiB 上限。删除定位后需保存页面，才能移除已被页面引用的资源；历史发布版本及快照继续保留原资源。
- **T29.6**：新用例已接入 `npm test`；浏览器用例在两个项目中用表单创建分组、排序、筛选、行列转换、映射、关联和函数步骤以及父子集合，再验证试算、分页错误定位、图片、保存重开、发布、生成和界面签发。原流程的签发已改为实际点击按钮，继续检查历史下载/重印的文件哈希。

## 项目验收边界

上述验证使用仓库中的合成 MES 数据和示例模板，证明公共链路与配置交互可用。真实项目还需提供客户 Excel、脱敏 MES 数据及认可的对照结果，核对特殊计算、字体、纸张、Office/WPS 打印效果。PDF 仍沿用已配置的固定版式能力；未配置运行环境的 PDF 用例不代表通过实际渲染验收。
