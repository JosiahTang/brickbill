# 通用 Excel 单据工具编程任务书

日期：2026-10-02。当前基础版本：v0.2.0。本文定义通用 Excel 单据工具的开发任务，状态见下方进度说明。接口、目录及版本选择按实际实现更新。

目标是让不同 MES 项目通过项目数据适配、数据视图配置和 Excel 模板配置生成复杂单据。达力普采用的 BFR 作为业务规则和输出结果的参考。通用工具负责 Excel 模板设计、字段绑定、数据组织、分页和生成，项目负责提供可关联的业务数据。

## 产品范围和完成标准

首个可交付版本必须完成以下闭环：选择项目及业务单号，读取标准数据集，选择已发布模板，执行数据视图，按固定版式分页，预览全部页面，导出 XLSX，并保存本次生成快照。设计人员能够导入、编辑、保存和重新打开多工作表模板。

达力普以质保书打印号作为查询入口。数据仍保留产品类别、物料明细标识、炉号、试批号、试样和试验序号等关联维度；具体组合键由源表映射确认。其他项目可用不同的业务单号和数据库结构。

首期必备：字段字典管理、项目适配、数据视图、注册函数、多工作表模板、主表与续页及附页、多区域联动分页、页面字段、图片定位、模板版本、生成快照、HTTP 接入和现有宿主兼容。积木功能继续不纳入开发。

流式分页列入后续必做任务 T21。PDF 列入可选任务 T22。首期不承诺任意 Excel 特性兼容；不实现任意脚本执行、通用 SQL 设计器、宏、旧版 XLS、图表或透视表编辑、全功能 Excel 公式计算。布局发生变化时仍需阻止无法安全处理的公式引用；统计计算通过字段和视图提供。

产品完成标准：同一项目增加两个数据组织不同的客户模板，无需增加模板专用后台函数；接入第二个项目时，公共引擎不出现项目名称、表名或客户分支。确需新增算法时，开发一个有版本的公共函数，由多个模板复用。

## 实施约定

1. 公共领域模型、转换和分页引擎采用 TypeScript，避免依赖 Vue、DOM、数据库驱动和项目表名。前端沿用现有 Vue、Univer 和 ExcelJS；不在规划阶段更换技术栈。
2. 新增 Node.js 参考服务以复用公共引擎。其他项目可通过 HTTP 集成，不要求重写其 C++、Java 或 .NET 后台。实际部署可复用项目已有网关、认证及存储设施。
3. 先提供模拟适配器和 JSON 数据输入，再提供项目侧 HTTP 数据适配。数据库查询放在项目适配层；浏览器不接数据库。
4. 模板绑定使用稳定的 `fieldId`，数组区域使用 `viewId` 或 `datasetId`。物理字段名和 JSON 路径由适配或视图管理。已发布模板固定引用字段目录、视图、函数和布局版本。
5. 先执行数据组织，再生成页面计划，最后把页面计划投影到预览和 XLSX。页面计划保留来源记录标识及分组键，合并、隐藏重复值和补白不得修改原始数据。
6. 首期默认采用固定版式，允许同一页多个区域按相同业务组联动。主表、续页和附页分别指定页面定义；具体签章和备注出现范围由模板配置。
7. 首期 XLSX 输出约定为一个逻辑页对应一个可见工作表，按页序排列，并设置各表打印区域、纸张和方向。T14 自动回读已校验投影和文件结构；在指定办公软件版本中每表实际打印一页仍须现场验证，不依赖无限缩小字体掩盖溢出。单工作表纵向拼页可作为后续输出适配。
8. 同一快照、模板、规则版本及显式语言和时区参数，必须得到相同的字段值、页面计划和总页数。生成时间、文件标识等运行元数据不参与业务结果比较。

## 编程任务

### T01 定义跨项目契约和迁移规则

优先级：P0；阶段：M1；职责：公共核心；依赖：无。

开发内容：定义 `ProjectDefinition`、`DatasetBundle`、`FieldCatalog`、`DataViewDefinition`、`TemplatePackage`、`PagePlan`、`GenerationSnapshot`。明确数据表粒度、主键、关系基数、字段类型、单位、空值、来源追踪和各类版本。错误结构包含错误码、任务阶段、视图或区域标识以及可定位字段，不以一条普通字符串丢失上下文。

建议位置：新增 `src/core/contracts/`、`schemas/v2/`、`docs/contracts-v1.md`。为 v0.2 单表文档和嵌入元数据定义迁移；原单元格样式和绑定不得静默丢失。遇到未知更高版本应拒绝并说明原因。

验收：契约示例全部通过 Schema；旧文档可迁移成单工作表模板包，布局和绑定一致；错误集合类型、重复主键、悬空关系和不支持版本均产生明确错误。交付契约、示例、迁移规则及对应测试。

### T02 建立复杂单据和跨项目样例数据

优先级：P0；阶段：M1；职责：领域分析与验证；依赖：T01。

开发内容：在 `tests/fixtures/reporting/` 建立合成的达力普形态数据和第二项目数据。包含合同、物料、成分、力学、检验要求及关联键；为相同业务内容提供两种不同源字段结构。建立单页、多页、不等长试样、附页和异常数据样例，以及预期的组、记录数和汇总结果。

验收：样例至少覆盖 V01 至 V14；每个预期结果能追溯到具体源记录。图片遮挡部分不作真实数据还原。真实样本另行脱敏接入，合成样例不作为生产数据验证证据。

### T03 实现项目数据适配接口

优先级：P0；阶段：M1；职责：服务端与项目适配；依赖：T01、T02。

开发内容：实现 `ProjectAdapter.collect(context)`，输入项目、单据类型、业务单号及允许的业务参数，输出 `DatasetBundle`。提供内存样例适配器和项目 HTTP 适配器，配置源字段映射、类型转换、键和关系。数据分表保存，不将多个一对多集合直接展开成一张宽表。采集到的数据记录源版本或读取时间与一致性说明。

建议位置：新增 `server/adapters/`、`examples/projects/`。服务器配置可调用的数据源；前端只选择已登记项目。项目已有落地数据优先复用。

验收：同一业务内容的两个适配器输出等价的标准数据；打印号无记录、类别不明确、重复主键、关系缺失、HTTP 超时均可定位。只读采集不执行旧系统分页写回，不依赖 BFR 返回的布局数据。

### T04 实现字段目录和稳定绑定解析

优先级：P0；阶段：M1；职责：公共核心；依赖：T01、T03。

开发内容：字段增加稳定标识、数据集、粒度、类型、单位、来源和版本。支持数据源字段、常量、运行参数、派生字段及页面系统字段。字段新增必须明确取值来源。区分项目业务字段与模板标签、数字格式等显示覆盖。提供目录版本解析和引用检查。

建议位置：新增 `src/core/catalog/`，兼容 `src/domain/fields.ts` 和旧 `path` 绑定。

验收：源列名改变但映射及 `fieldId` 保持时，模板仍正常取值；字段显示名变化不破坏绑定；删除、变更已引用字段类型会提示受影响的模板；已发布模板不被目录草稿修改影响。

### T05 实现通用数据视图执行器

优先级：P0；阶段：M1；职责：公共核心；依赖：T01、T02、T03、T04。

开发内容：实现受控的过滤、排序、按业务键分组、投影、聚合、行列转换和父子集合组织。关联只沿已声明的关系执行并校验基数；一对多结果保留集合。重复测点的选择策略必须显式配置，不能默认取第一条、最新一条或平均值。支持嵌套记录，并保留每个输出值的来源记录标识。

建议位置：新增 `src/core/views/`。视图输出具有稳定 Schema 和版本，供模板字段目录使用。运行顺序为有限、可校验的操作序列，不提供任意脚本。

验收：同一打印号下 2 条成分和 3 条力学记录保持各自数量，物料数量及重量不被放大；相同取值的不同业务记录不被误删；行列转换遇到相同键的多个值时按明确策略处理或报错；数值零、空值和“不适用”分别保留。

### T06 实现版本化公共函数注册

优先级：P0；阶段：M1；职责：公共核心与业务规则；依赖：T01、T05。

开发内容：函数通过 `functionId + version` 注册，声明输入 Schema、输出 Schema、参数和错误。函数输入为已采集的数据，输出为结构化记录，避免直接读数据库、写页码或修改模板。第一批实现硬度按试样、象限、位置及测点组织的函数，并将正式结果选择规则作为单独策略。

建议位置：新增 `src/core/functions/`。函数由代码注册，模板只引用已登记函数，不携带可执行源码。

验收：同一函数服务两套不同排版模板；未知函数或版本报错；输出 Schema 不符阻止生成；重跑结果一致，输入数据不被修改。旧 MES 已提供正式平均值或单位换算值时不重复计算。

### T07 实现多工作表模板包和兼容保存

优先级：P0；阶段：M2；职责：公共核心与 Excel；依赖：T01、T04。

开发内容：增加 `TemplatePackage` 管理多个可编辑工作表、视图引用、页面定义、资源和版本。原始工作簿及图片资源在包级保存，避免各工作表重复保存整本 Base64。保留 v0.2 导入路径；新增包级迁移、Schema 校验和工作表稳定标识。

建议位置：新增 `src/core/templates/`，修改 `src/export/importExcel.ts`、`src/export/excel.ts`、`src/stores/designer.ts`、`src/stores/persistence.ts`。

验收：至少三个工作表分别绑定字段，保存后全部恢复；重命名或调整工作表顺序不破坏区域引用；重复保存体积不递归增长；切表、撤销重做和草稿恢复保持各表状态；未参与模板的工作表按支持范围保留。

### T08 改造字段字典和拖拽界面

优先级：P0；阶段：M2；职责：前端；依赖：T04、T07。

开发内容：字段面板按项目、数据集和视图分组，显示类型、单位和所属集合。提供字段新增、编辑、来源配置、搜索和使用位置查询。将常量、参数和页面字段与业务字段区分展示。拖拽时检查目标区域的记录作用域，合并格仍绑定左上角。

建议位置：拆分 `src/components/TemplateDesigner.vue`，新增 `src/components/fields/`、`src/components/templates/`。

验收：业务用户可增加常量和允许的派生字段；新增无来源字段不能发布；父字段可绑定到子明细上下文，互不相关集合字段会给出原因；支持撤销、删除引用检查和稳定字段标识保存。

### T09 实现数据视图配置界面

优先级：P0；阶段：M2；职责：前端；依赖：T05、T06、T08。

开发内容：提供数据集选择、条件、分组键、排序、输出字段、汇总、行列转换及注册函数参数配置。显示输入记录、输出记录和来源定位，保存视图草稿和版本引用。复杂规则可由技术人员维护配置文件，普通设计人员选择已经发布的视图。

建议位置：新增 `src/components/views/`，调用统一执行接口；前端不另写一套业务计算。

验收：不写代码即可配置“全部成分结果”和“按明确正式标记选择结果”两种视图；错误关系或不匹配函数参数不能保存为有效版本；视图预览与同一版本正式生成的业务数据一致。

### T10 实现页面和区域设计配置

优先级：P0；阶段：M2；职责：前端与公共核心；依赖：T07、T08。

开发内容：允许从工作表选区定义主表、续页、附页及可重复页面版式，设置纸张、方向、页边距和打印范围。框选固定区域、明细区域、表头、标准上下限、声明和签章。配置固定行数或可用高度、组键、排序、空数据行为、补白、页内编号及整单编号。

为多个明细区域设置相同的 `paginationGroupId`；配置组保持完整、超大组处理、区域及附页出现条件，和内容在每页、首页或末页出现的范围。联动区域必须使用兼容的业务组键。多个区域可以有不同数据集和记录数。

建议位置：新增 `src/core/layout/config.ts`、`src/components/pagination/`。

验收：同一模板能配置成分区和力学区联动，以及条件硬度附页；区域重叠、无效续页引用、循环附页关系和缺少共同组键均有定位提示；保存再打开配置不丢失。

### T11 实现布局测量与溢出诊断

优先级：P0；阶段：M2；职责：布局引擎；依赖：T07、T10。

开发内容：统一使用可换算的物理尺寸，计算列宽、行高、合并格、边框、图片范围和可打印区域。固定行高按配置严格计算；自动换行内容通过可替换的字体测量接口计算高度。建立支持字体集和字体缺失报告，标明测量误差需要在目标办公软件中校准。

建议位置：新增 `src/core/layout/measure.ts` 及浏览器、服务端测量适配。显示配置约束内的缩放比例；超过允许缩放、长文本放不下或图片越界时，返回具体位置并阻止发布或正式生成。

验收：中英文换行、窄列、多层表头、跨行合并、固定页尾和大尺寸图片都有确定的测量结果；不通过截断文本、覆盖下方区域或无限缩小来通过验收。无完整字体测量时可以继续固定行高路径，但需提示可能溢出并完成实印验证。

### T12 实现固定版式与联动分页引擎

优先级：P0；阶段：M2；职责：公共核心；依赖：T05、T06、T10、T11。

开发内容：按稳定组键和排序遍历业务组，测量该组在每个联动区域中占用的行数或高度。只有所有区域都可容纳时才加入当前页；任一区域不足则换页。空集合按配置保留或隐藏；缺少某类结果不能使其他区域试批错位。预留重复表头、标准行和页尾空间。

当单组超过一整页时，默认返回 `GROUP_TOO_LARGE`；模板配置了附页或允许的子记录续页规则才执行该路径。不得把不完整试验组任意切开。生成主表及条件附页的页序，完成所有页后回填页码和总页数。首末页内容改变可用空间时重新计算，设置收敛检查避免循环。

## 接口开发清单

以下为 T01 和 T17 应实现的最小接口语义，具体 OpenAPI 在 T01 固化。项目身份由服务端鉴别并校验，不能仅信任请求中的 `projectId`。

| 方法和路径 | 用途 | 必须返回的核心信息 |
| --- | --- | --- |
| `GET /api/projects` | 已登记项目 | 项目标识、支持的单据类型和查询参数 |
| `GET /api/projects/{projectId}/catalog` | 业务字段目录 | 目录版本、字段、数据集、粒度和关系 |
| `POST /api/projects/{projectId}/views/preview` | 视图试算 | 输出 Schema、记录、来源、诊断 |
| `PUT /api/projects/{projectId}/views/{viewId}/draft` | 保存视图草稿 | 修订号及引用检查 |
| `POST /api/projects/{projectId}/views/{viewId}/publish` | 发布视图 | 不可变版本及函数依赖 |
| `PUT /api/projects/{projectId}/templates/{templateId}/draft` | 保存模板包 | 修订号、资源引用及校验结果 |
| `GET /api/projects/{projectId}/templates/{templateId}/versions/{version}` | 打开已发布模板 | 固定版本的模板包及资源 |
| `POST /api/projects/{projectId}/templates/{templateId}/publish` | 发布模板 | 不可变版本及固定依赖 |
| `POST /api/projects/{projectId}/generations` | 预览或正式生成 | 生成标识、状态、快照及版本信息 |
| `GET /api/projects/{projectId}/generations/{generationId}` | 状态和结果查询 | 阶段、错误、总页数和下载引用 |
| `GET /api/projects/{projectId}/generations/{generationId}/pages/{pageNumber}` | 逐页预览 | 页面尺寸、单元格、图片、页码和诊断 |
| `GET /api/projects/{projectId}/generations/{generationId}/file` | 下载既有文件 | 已确认生成结果的 XLSX 字节 |
| `POST /api/projects/{projectId}/generations/{generationId}/reprint` | 按快照重印 | 原结果或固定版本的重放结果 |

视图和模板草稿读取、历史列表、停用及资源上传下载接口随存储任务补齐。并发保存携带预期修订号；生成携带幂等键。用户确认预览后正式保存应复用既有快照，必要时增加“预览结果转正式记录”接口，不再次采集。

正式生成输入示例：

```json
{
  "mode": "issue",
  "documentType": "qualityCertificate",
  "businessKey": { "printNo": "DEMO-QC-001", "productPart": "T" },
  "templateRef": { "id": "customer-a-certificate", "version": 1 },
  "locale": "zh-CN",
  "timezone": "Asia/Shanghai",
  "idempotencyKey": "demo-request-001"
}
```

`printNo` 和 `productPart` 是达力普形态适配的业务参数示例，不是所有项目的固定字段。正式生成只能使用已发布版本；预览草稿必须携带准确修订号。自动模板匹配是显式模式，并返回实际命中的版本。

建议统一错误码：`DATA_NOT_FOUND`、`AMBIGUOUS_SCOPE`、`DUPLICATE_KEY`、`RELATION_CARDINALITY_ERROR`、`FIELD_NOT_FOUND`、`VALUE_TYPE_ERROR`、`RULE_VERSION_NOT_FOUND`、`GROUP_TOO_LARGE`、`LAYOUT_OVERFLOW`、`PAGE_PLAN_NOT_CONVERGED`、`TEMPLATE_MATCH_AMBIGUOUS`、`REVISION_CONFLICT`、`UNSUPPORTED_FORMULA_LAYOUT`、`SOURCE_TIMEOUT`。每个错误必须具有用户可读说明和具体位置。
