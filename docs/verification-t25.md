# T25 验收记录

T25 增加项目接入初始化、离线校验和只读探测命令。新增流程使用已有注册器、`HttpProjectAdapter`、字段目录、契约检查及 `DataViewEngine`；未增加数据库驱动或项目特定核心逻辑。

## 已核对目标

- `npm run project:init -- --example dalipu --output <路径>` 生成可编辑配置，文件已存在时拒绝覆盖；也支持 `general-mes`。
- `npm run project:validate -- --config <配置> [--sample <采集样本>]` 无需 MES 连通或令牌即可校验配置；传入样本时经现有映射适配器采集并执行全部登记视图。
- `npm run project:probe -- --config <配置> --project <项目标识> --request-file <请求文件> --output <报告路径>` 使用现有只读 HTTP 适配器完成请求与数据映射，执行全部登记视图并保存 JSON 诊断报告。
- 探测报告包含项目、适配器、字段目录和源版本，数据集/视图记录数及失败诊断；不保存业务单号值、源记录或令牌。缺少令牌及数据源错误也会落失败报告。
- 服务原有注册加载默认继续校验项目令牌；CLI 离线校验只关闭令牌存在性要求，不放宽契约、字段映射或视图定义检查。
